# План исправления: ложные уведомления об изменении статуса

## Проблема

`StatusChanged()` сравнивает кортеж `(avail, delivery, since)`. Поле `since` — это временная метка, когда текущие значения `avail`/`delivery` стали актуальными. Оно может меняться даже если сами значения не изменились, что приводит к ложным уведомлениям.

## Решение

### 1. Исправить `StatusChanged()` в `state.go`

Сравнивать только `(avail, delivery)`, игнорируя `since`:

```go
func StatusChanged(old, new *FuelState) bool {
    if old == nil {
        return true
    }
    return old.Avail != new.Avail || old.Delivery != new.Delivery
}
```

### 2. Обновить `main.go` — убрать `Since` из `newState`

В `checkAndNotify()` при формировании `newState` убрать поле `Since`:

```go
newState := &FuelState{
    Avail:    fuel.Rest.Avail,
    Delivery: fuel.Rest.Delivery,
    Status:   currentStatus.Status,
}
```

### 3. Сообщение Telegram

`since` в сообщении берётся из `currentStatus.Since` (из API) — это уже реализовано правильно.

## Файлы

- `state.go` — `StatusChanged()`
- `main.go` — убрать `Since` из `newState`
